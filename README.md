# 🔐 Projet RGPD — X-Corp

## 📌 Présentation

Ce projet a pour objectif d'étudier et de mettre en pratique les principales exigences du **Règlement Général sur la Protection des Données (RGPD)** à travers le cas d'une entreprise fictive : **X-Corp**.

L'étude porte notamment sur la gestion des données personnelles, l'analyse des risques et la mise en conformité de l'entreprise.

## 📚 Travaux réalisés

| Étape | Réalisation |
|---|---|
| **Jour 1** | 📖 Étude des concepts clés du RGPD |
| **Jour 2** | 📋 Création du registre des traitements |
| **Jour 3** | 🔎 Réalisation d'une DPIA pour HealthMed |
| **Jour 4** | 🚨 Simulation d'une violation de données |
| **Jour 5** | ✅ Audit de conformité RGPD et plan d'action |

## 🛡️ Notions abordées

`RGPD` `CNIL` `DPO` `DPIA / AIPD` `Gestion des risques` `Violation de données` `Audit de conformité`
